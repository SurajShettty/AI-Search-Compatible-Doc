## User Wise Mess Report

<!-- id: user-wise-mess-report | category: Hostel Analytics Reports -->

**What it does**

This report provides a comprehensive breakdown of meal consumption at an individual user level, capturing the total count of each meal type availed by a student based on institutional meal configuration.

**Why it matters**

It offers a clear and detailed view of individual mess usage, helping understand student meal preferences and consumption patterns.

**How to use**

1. This report is available in the Analytics module under the Hostel section in the Mess tab.

**Examples**

- If a university has three meal types configured like Breakfast, Lunch, and Dinner, this report will display the total number of times each meal has been availed by the respective student.

## Mess User Date Wise Report

<!-- id: mess-user-date-wise-report | category: Hostel Analytics Reports -->

**What it does**

This report provides a detailed record of meal consumption at an individual level, tracking which user availed which meal, at which mess, and on what date, along with the admin responsible for enabling the coupon.

**Why it matters**

It supports mess utilization monitoring, user-type segmentation, and admin accountability, serving as a reliable reference for auditing meal activity and understanding overall mess usage patterns across the institution.

**How to use**

1. This report is available in the Analytics module under the Hostel section in the Mess tab.

**Examples**

- Administrators can track which user availed which meal, at which mess, and on what date — along with the admin responsible for enabling the coupon.
