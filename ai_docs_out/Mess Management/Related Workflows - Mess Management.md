# Related Workflows

**Module:** Mess Management  
**Tags:** Mess Management, Workflows, Meal Services, Custom Workflows, Workflow Automation, Digii Platform


## Overview

This document outlines various custom workflows related to mess management and meal services within the Digii platform. These workflows, configurable by the Mess Administration team via the Workflow Automation module, allow users to submit specific requests and feedback forms.

## Prerequisites

- **Workflow Automation module** — The Workflow Automation module must be enabled and configured to set up and manage custom mess-related workflows.
- **Mess Administration team** — The Mess Administration team is responsible for configuring and managing all mess-related workflows and processing user requests.
