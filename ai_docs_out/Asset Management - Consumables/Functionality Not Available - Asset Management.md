<!-- id: deleting-product | category: Product Management -->

**What it does**

The functionality to delete a product is not supported once it has been created in the Asset Management module for Consumable Assets.

**Why it matters**

Users cannot remove product records from the system, which may lead to outdated or incorrect data persistence and clutter in the product list.

## Editing Allotment Details

<!-- id: editing-allotment-details | category: Allotment Management -->

**What it does**

Allotment records cannot be modified after allotment. Asset Administrators will have to return all the quantity allotted and make a new allotment record.

**Why it matters**

Correcting allotment errors requires a multi-step process of returning and re-allotting, which is inefficient, time-consuming, and prone to further errors or data inconsistencies.

**How to use**

1. Return all the quantity previously allotted.
2. Create a new allotment record with the correct details.

**Examples**

- If an administrator accidentally allots 10 pens instead of 5, they must first return all 10 pens and then create a new allotment for 5 pens.
- To change the recipient of an allotted item, the original allotment must be returned, and a new one created for the correct recipient.

## Bulk Upload of Purchase Details

<!-- id: no-bulk-upload-purchase-details | category: Purchase Management -->

**What it does**

Administrators cannot upload multiple purchase details at once using an Excel file. Each batch must be added individually.

**Why it matters**

Manually adding each purchase record is time-consuming and inefficient, especially for large volumes of purchases, increasing administrative workload and potential for data entry errors.

**How to use**

1. Add each batch of purchase details individually through the user interface.

**Examples**

- If an administrator has 50 purchase records to enter, they must input each one separately instead of using a single Excel upload.
- There is no option to import a CSV or Excel file containing multiple purchase entries.
