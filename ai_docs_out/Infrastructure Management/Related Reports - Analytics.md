## Infrastructure Report

<!-- id: infrastructure-report | category: Infrastructure Utilization -->

**What it does**

The Infrastructure Report provides comprehensive details of all infrastructure configured on the Digii platform. It indicates whether a venue is available for booking and specifies which user types are permitted to book each venue.

**Why it matters**

This report is crucial for effective campus management, allowing administrators to monitor facility utilization, manage venue bookings efficiently, and ensure proper access control for different user groups, optimizing resource allocation.

**How to use**

1. 1. Access the Admin Console.
2. 2. Navigate to the Analytics Module.
3. 3. Select the Infrastructure Section.
4. 4. Go to the Infrastructure Utilization Dashboard.
5. 5. Click on the Reports tab.

**Examples**

- An administrator can use this report to quickly identify all available lecture halls for a new course schedule.
- It can show which specific labs are restricted to faculty members only, preventing unauthorized student bookings.
- The report helps in understanding the overall utilization of campus facilities like auditoriums and sports grounds.
